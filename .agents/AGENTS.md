# Disposable Disciples — Agent Rules

## Testing & Verification

**Never start the dev server or launch a browser to test changes.**

The user always does manual testing themselves. This applies to:
- Running `npm run dev`, `vite`, or any other dev server command.
- Launching a browser subagent to visually verify behaviour.
- Starting `npm run build` unless explicitly asked.

After making code changes, simply explain what was changed and why, then stop. Do **not** attempt to verify visually.
